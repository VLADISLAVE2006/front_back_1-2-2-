Практическая работа №15 (Service Worker + стратегии кэширования)
Цель
Настроить продвинутое кэширование для офлайн-работы.

Что сделано
Реализованы две стратегии кэширования:

Cache First – для статических ресурсов (App Shell)

Network First – для динамических страниц (/content/*)

Созданы два отдельных кэша: app-shell-v2 и dynamic-content-v1

Добавлен fallback для офлайн-режима (загрузка home.html из кэша)

Настроена автоматическая очистка старых кэшей при активации

Результат
Приложение полностью работает офлайн, страницы загружаются из кэша при отсутствии сети.

Практическая работа №16 (WebSocket + Push-уведомления)
Цель
Добавить синхронизацию в реальном времени и push-уведомления.

Что сделано
Создан сервер на Node.js + Express + Socket.IO

Сгенерированы VAPID-ключи для push-уведомлений

Реализованы эндпоинты:

POST /subscribe – сохранение push-подписки

POST /unsubscribe – удаление push-подписки

Добавлена кнопка "Включить уведомления" с запросом разрешения

Реализована отправка push-уведомлений всем подписчикам при добавлении заметки

Настроен WebSocket для мгновенной синхронизации между вкладками

Результат
При добавлении заметки во второй вкладке сразу появляется всплывающее сообщение

Push-уведомления приходят даже при закрытом браузере

Кнопка "Отключить уведомления" отключает только push, WebSocket продолжает работать

Практическая работа №17 (Напоминания)
Цель
Добавить функционал напоминаний к заметкам.

Что сделано
Доработана форма добавления заметки (поля date и time)

Изменена структура данных в localStorage:

json
{
  "id": 123456789,
  "text": "Купить молоко",
  "reminder": 1700000000000,
  "createdAt": 1699999999999
}
На сервере реализовано планирование напоминаний через setTimeout

Добавлено хранилище активных таймеров (Map)

Реализованы обработчики Socket.IO:

newTask – планирование напоминания

deleteTask – очистка таймера

snoozeReminder – откладывание напоминания

В Service Worker добавлены действия для уведомлений:

"Отложить на 5 минут" – перенос напоминания

"Выполнено" – удаление заметки

Добавлена кнопка "Отложить на 5 минут" в интерфейсе заметки

Результат
Напоминания работают даже при закрытом приложении

Push-уведомления приходят в указанное время

Уведомления содержат кнопки для взаимодействия
