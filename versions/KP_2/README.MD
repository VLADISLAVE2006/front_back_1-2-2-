## Практическая работа №7

### Цель
Создать базовый сервер для интернет-магазина с REST API.

### Что сделано
- Создан сервер на Node.js + Express
- Реализованы базовые CRUD операции для товаров
- Добавлена in-memory база данных (массив products)
- Настроена маршрутизация:
  - `GET /api/products` – получить список товаров
  - `GET /api/products/:id` – получить товар по id
  - `POST /api/products` – создать товар
  - `PUT /api/products/:id` – обновить товар
  - `DELETE /api/products/:id` – удалить товар
- Подключен Swagger для документации API

### Результат
Рабочий REST API для управления товарами без аутентификации.
